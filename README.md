# desafio-caed-data-mining
Mineração de Dados em um dataset massivo de letras de músicas. Inclui: exploração e limpeza da base, rede de colaboração entre artistas, geração de letras com GPT-2, predição de gênero musical e análise de polaridade, combina técnicas de pré-processamento, aprendizado supervisionado e não supervisionado, grafos e processamento de linguagem natural.
